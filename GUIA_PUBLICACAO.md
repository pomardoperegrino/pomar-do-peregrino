# Como publicar o Pomar do Peregrino no GitHub Pages

O repositório já contém `index.html`, `catalogo.html` e as fichas botânicas. Para torná-los acessíveis por um endereço público, o responsável pelo repositório deve ativar o GitHub Pages:

1. Abra https://github.com/pomardoperegrino/pomar-do-peregrino/settings/pages (entre na conta, se necessário).
2. Em **Build and deployment**, selecione **Deploy from a branch** como fonte.
3. Em **Branch**, escolha **main** e a pasta **/(root)**.
4. Clique em **Save**.
5. Aguarde o GitHub informar o endereço público em **Settings → Pages**. O processo pode levar alguns minutos.
6. Abra o endereço informado e teste o catálogo e as fichas no celular.

O endereço normalmente segue o formato `https://pomardoperegrino.github.io/pomar-do-peregrino/`, mas **não considere esse endereço confirmado antes de verificar a publicação**.

Depois de publicado, teste estas rotas:

- `catalogo.html`
- `laranjeiras-croqui.html`
- `ficha-individual.html?codigo=B07`
- `ficha-individual.html?codigo=B08`

**Antes de imprimir QR Codes:** confirme o endereço público final, verifique a identidade e o plantio da árvore e valide o nome do doador. O QR Code deve apontar para a URL completa da ficha individual, e não para o endereço do arquivo no GitHub.

Se o botão de salvar não aparecer ou houver restrições de acesso, confira as permissões da conta e as configurações do repositório.
